03

The real opportunity: stop being a map, start being an instrument

ATLAS currently visualizes public news. That's a demo. What makes it a tool an outfit like Forensic Architecture, Bellingcat, or an NGO monitoring team would actually reach for is answering questions a reporter can't answer by hand — starting with the niche the schema is already halfway built for: OSINT verification tooling, not just event aggregation.

Overhead-satellite lookup Feasible now

"Which satellite could have imaged this coordinate at this time?" is the single most common first question in a geolocation investigation, and it's a solved problem with public data — nobody has wired it into a public map yet.

How: pull TLE (orbital element) sets from CelesTrak's free API for Earth-observation constellations (Sentinel-2, Landsat, Planet's public catalog, commercial imaging sats with public TLEs), propagate with SGP4 (satellite.js on the frontend or python-skyfield on the backend — both free, both fast enough for interactive use), and answer: for a clicked point + time window, which satellites had it in view, and roughly what resolution/angle. Cross-reference against Sentinel Hub's actual acquisition catalog (also free, API-keyed) to move from "could have" to "did." This is exactly the kind of capability that turns a browsing tool into an investigation tool.
Evidence chain-of-custody export Schema exists, unused

The Prisma schema already has EvidenceItem, Claim, FactCheck, Contradiction, and SatelliteObservation models — a full forensic data model, built and never wired to any route. This is the single biggest gap between "map" and "investigative package."

How: wire the existing models into a real ingest path (not the JSON seed shortcut currently used), then add one export: a signed, hash-chained JSON packet per case — source URLs, archive.org/archive.today snapshots, timestamps, a SHA-256 of each artifact. That's the same shape Forensic Architecture's own methodology publishes as an "evidence file." Doesn't need blockchain or anything exotic — just a signed manifest, which is what actually matters for admissibility discussions.
Tiered public/private Live map Architecture pattern exists in-org

You asked for a 24/7-hosted map with real capabilities, self-hostable, safe to test locally. SeaCommons already solved exactly this problem — a privacy-filtered public projection served by an edge worker, with the full operational picture behind auth. That's the correct shape for ATLAS too: public visitors see a redacted, delayed, aggregated view; an authenticated operator console sees raw signals, source chains, and the satellite/evidence tooling above.

How: don't reinvent this — port the pattern. ops/ already targets self-hosted VM deployment with local Ollama (zero external API dependency, genuinely air-gapped-capable), which is the right foundation for "install locally, test safely." Add a docker-compose.yml that starts Postgres + the app + Ollama in one command, matching what SeaCommons's docker-compose.pilot.yml already demonstrates works.
04

Handle with care: the investigation/ folder

⚠ Not for integration as-is

SITI/investigation/_FORENSIC_ANALYSIS was checked at the directory-listing level only — filenames, not contents — and that was already enough to see this is an active real case with identifiable individuals, photos, and video, not a generic OSINT example set. It was not opened further, and nothing from it appears anywhere in this document, the codebase, or any commit.

What's genuinely reusable is the directory shape — osint/, satellite/, security/, ui/ as separate concerns — which is a reasonable module boundary for ATLAS's own forensic layer. That structure can inform the design. The case files inside it must never be copied, referenced, screenshotted, or committed into a public repository under any circumstance. If any tooling script in there (a satellite-pass calculator, a hashing utility) is worth lifting, it gets rewritten clean-room against public/synthetic test data, reviewed for any embedded case references, before it goes anywhere near republic-xyz.
